## Getting Started

First, run the development server:

```bash

# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Multiple roles

System admins can create or edit an account at `/create_account`, choose its primary role, and check any secondary roles. The same email and password work for all assigned roles. After login, the user can select a role in the top-right menu. Switching opens that role's dashboard and refreshes its permissions, notifications, and badges. Shared role titles have separate society and department entries in the menu.

After pulling schema changes, run `npx prisma migrate deploy` and `npx prisma generate` before starting the app. Existing accounts retain their primary role and start with no secondary roles.

With the local server running, `npm run test:roles` verifies account assignment, role switching, permission isolation, and role revocation. It uses temporary test accounts in the configured database and removes them afterward.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
